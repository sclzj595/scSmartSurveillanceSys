# Git 版本管理方案

> 本方案是 PRD v2.0 第 13 章的操作规范，与 [PRD-智能安防监控平台-v2.html](PRD-智能安防监控平台-v2.html) 保持一致。

## 远程仓库

```
https://github.com/sclzj595/scSmartSurveillanceSys.git
```

## 分支模型（单人项目，轻量优先）

- `main`：主干。**始终保持可编译、可运行**，与远端同步。
- 常规改动直接提交 `main`；涉及多文件的大重构可开 `feature/*` 分支，完成合回后删除。
- 禁止在 `main` 上提交编译不过的代码。

## 提交规范

格式：`type: 中文摘要`（详情写在提交体）

| type | 用途 | 约束 |
|---|---|---|
| chore | 构建/配置/杂务 | — |
| feat | 新功能 | — |
| perf | 性能优化 | **必须附修改前后的测量数据**（诊断角标截图或数值） |
| fix | 缺陷修复 | 注明对应缺陷编号（D1~D9）或问题现象 |
| refactor | 重构（不改行为） | 编译通过 + 行为等价说明 |
| docs | 文档 | — |

每次提交只解决一个问题。临时实验代码不进入 `main`。

## 标签与基线

格式：`vX.Y.Z-阶段名`，**只打在经过运行验证的提交上**（编译通过还不够）。

| 标签 | 提交 | 说明 |
|---|---|---|
| `v0.1.0-baseline` | `8fd24e8` | 课程版基线：功能完整、已运行验证；已知 D1/D2 延迟卡顿 |
| `v0.2.0-pipeline` | （待打） | 异步识别管线重构 `a647f6d`，编译已通过，**待运行验证后打标** |

回退路径：

```bash
# 查看基线（不动工作区）
git checkout v0.1.0-baseline          # 进入 detached HEAD，看完 git switch main 返回

# 整体回退到基线（丢弃其后所有未推送修改，慎用）
git reset --hard v0.1.0-baseline
```
