### 核心架构成果

- **算法库组件化（2026-10-17）**：人脸识别抽为独立可插拔算法库 **FaceAlgorithm.dll**（f:/CODE/Qt_forNoVS/FaceAlgorithm，独立仓库，MinGW 8.1 同链）。纯 OpenCV+STL 业务无关，`detectAndRecognize` 统一接口输出框/label/相似度/抓拍图；一套算法支撑**人脸闸机门禁 + 智能安防监控**双项目复用。监控端 FaceRecognition 已降为业务适配器（净删 316 行），smoke 回环测试 PASS（注册后自识别 sim=100）
- **异步识别管线**：采集线程 → FrameBank 最新帧槽 → 分析线程（25Hz 自适应跳帧）→ GUI 渲染节拍（30fps）；GUI 线程零 CV 计算，延迟上界 = 单帧处理耗时
- **数据/呈现分离**：引擎只产出结构化 AnalysisResult，标注由 OverlayRenderer 统一绘制（QPainter 中文渲染）
- **事件中心**：业务判定（冷却表 R2）+ 独立 worker 线程异步落盘，磁盘失败仅提示不阻塞识别（R4）
- **两段式异步人脸注册**：检测 → 弹窗预览/编辑姓名 → 入库；同名=补充样本
